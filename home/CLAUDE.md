# graphify
**Using an existing graph.** When a codebase has a `graphify-out/` directory, run `/graphify query` first for architecture and relationship questions, before reading files broadly. Its claims fall under the doctrine's "A finding is a hypothesis" and "A summary outlives its source" bullets. Commits after its last build mark it stale. Query an existing graph freely. Building a new one is the user's call.
