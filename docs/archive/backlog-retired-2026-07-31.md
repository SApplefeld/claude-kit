# Backlog items retired 2026-07-31

Retired by the compact-session removal effort (`claude-kit_compact-session-removal_spec_v1.md`): the compaction engine these items were about no longer ships in the kit, so there is nothing left to probe, spot-check, or fix. Scott has moved off deliberate compaction entirely (fresh sessions or `/clear` between chapters, native auto-compaction on unattended runs, plan-doc recovery), no compacted session remains in use, and the engine is one `git revert` away if that ever changes.

- **Fork: should the compaction engine strip stale usage fields? (2026-07-09)** Every row the engine wrote carried the source session's billed-usage numbers, so `/context` on a freshly resumed compacted session showed the old token count until the first API call. The open question was whether a stale near-limit usage row could trigger native auto-compaction immediately after resume; the 2026-07-07 to 07-14 corpus could not answer it and the probe was never run. Retired with the engine: no engine-written rows will exist again, and existing compacted sessions are out of use.
- **Kit dogfooding follow-up from the 2026-07-15 hardening session.** The sparse preserve-verbatim path never executed live; every live compaction returned a complete summary set. The watch (spot-check a destination if the skipped-turns warning ever printed) can never fire again. Retired with the engine.
- **Destinations compacted before 2026-07-18 may be truncated.** Pre-segmentation emission silently dropped parallel-tool losing branches (measured: 53 of 1,074 rows on the active chain of one real destination). The engine was fixed and `assertSingleParentChain` made the failure loud, but destinations produced before the fix carry only what survived, with their `[UNCOMPACTED]` sources as the only recovery. The remaining work was a manual audit of compacted sessions still in use; none remain in use, and the sources were never deleted, so nothing recoverable is lost. If an old compacted transcript is ever resurrected, the check is: compare its active-chain row count against its `[UNCOMPACTED]` source, and prefer the source when the destination holds a small fraction of it.
