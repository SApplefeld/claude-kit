# Harness assumptions

This document collects the beliefs the kit's prose holds about Claude Code, the harness its sessions run on. Each belief is one a Claude Code release could falsify. Each carries the source that states it and the observation that would prove it wrong. It is the fixed surface for the kit's upstream watch: the kaizen skill's pass diffs the Claude Code changelog against this list rather than against the prose, whenever the installed version differs from the one recorded below. The entry is also where a session changing a rule that rests on one of these beliefs finds the belief's source and its falsifier. A source is a repo-relative path with a line number, a memory record, or, for a belief the harness itself states, the harness-supplied text quoted verbatim. A memory record is one file in the kit's memory store, which lives outside the repository under the operator's home directory in the tier the pointer names, and the memory-system skill states where each tier lives and how a record is read back. The document leaves out two things deliberately. The kit's responses to these beliefs are rules rather than facts about the harness. Beliefs about the kit's own code have their falsifying evidence in the tree and are checked by reading it.

Last diffed against: Claude Code 2.1.267

That line names the Claude Code version the beliefs were last checked against: the version they were written against until the first diff runs, and the version the upstream watch last ran against after it. Each diff covers the releases after the value it finds, then advances it. An entry that states a version inside its belief pins that belief to that version, which the line above never overrides. Skill and charter source lines resolve at commit `9297097` of this repository, since an edit to a cited file moves its lines. A memory record is cited by name and has no line.

## Compaction and session identity
