# Backlog

The living handoff and next-steps doc for the kit. It carries active items only. When an item is done, it moves out to a dated snapshot in `archive/` (`backlog-YYYY-QN.md`) rather than being struck through in place, so this file stays lean and readable.

Per-plan history does not live here. A plan's Chapters are its own append-only record and travel with the plan into `archive/` when it closes. This file is for cross-effort next-steps that do not belong to any single open plan.

- **Make `.kit/` self-ignoring instead of relying on the consuming repo (2026-08-16, from the kit-goal-queue security review).** Everything the kit writes under a project's `.kit/` is scratch that should never be committed: the goal state and its plan paths, the compaction checkpoint, the stop-failure marker. - **Silent store auto-sync: the fail-safe hardening deferred at ship (2026-08-19, from the worktree-store-and-autosync Section 2 close-out, `docs/plans/claude-kit_worktree-store-and-autosync_spec_v1.md`).** The auto-sync shipped after five review rounds, security-clean of any Critical or security-Major (the inbound screen converged to a completeness-proven mode+path allowlist).
